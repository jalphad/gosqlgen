# gosql

gosql is a work-in-progress Go SQL library for Postgres schemas. It generates a typed query API while keeping the rendered SQL visible.

This documentation follows the Diataxis structure:

- Tutorials teach a complete path through a small working task.
- How-to guides will cover focused tasks once the API stabilizes.
- Reference pages will document generated APIs and behavior contracts.
- Explanation pages will cover design tradeoffs and internals.

Start with the [Getting Started tutorial](tutorials/getting-started.md).
